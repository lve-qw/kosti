## Исправления аудита

- ZIP с конфликтом файла и каталога отклоняется до записи файлов.
- Проверка числа декодируемых пикселей предшествует выделению pixel_array.
- CSV экранирует потенциальные формулы из внешних строк.
- Некорректные и слишком длинные имена загрузок возвращают 400.
- Сбой генерации превью не теряет результаты основного анализа.
- Проекция передаётся с источником, неизвестное значение не угадывается.
- Release включает задание и тесты для воспроизведения проверки.
- GitHub CI проверяет изменения и допускает деплой только после успеха.

## Открытые ограничения

Распознавание оси позвоночника слабое (F1 0,059). Требуются дополнительная
разметка и эксперименты, независимая проверка индексации и внешняя валидация.
Набор разработки мал, идентификация независимых пациентов не подтверждена.
Нет обученного определения проекции без метаданных и измерения на H200.
HTTP-стенд без аутентификации предназначен для демонстрации.
