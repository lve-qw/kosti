## Передача работы

В текущем проходе параллельно реализуются DATA-01/02, ML-01/02, API-01/02; основной агент интегрирует QA-01 и OPS-01. Остальные задачи выделены отдельными этапами и не обозначаются выполненными до получения проверяемых результатов.

## Фактический статус первого прохода

- DATA-01/02: реализованы и проверены на всех 499 файлах; 252 уникальных изображения, три конфликтные строки экспертной разметки.
- ML-01/02: готовы загрузчики ResNet18-bundle, проверка классов/предобработки/контрольной суммы, маскированная функция потерь, групповые фолды, метрики и bootstrap. Исходный anatomy-checkpoint строго загружен в ResNet18 с 3 входными каналами и 2 выходами. Его точность и порядок классов не подтверждены.
- API-01/02: реализованы, есть тесты настоящего пути DICOM → PyTorch → API → CSV, обработки ошибок, дублей и небезопасных архивов.
- OPS-01: CLI проверен установленным пакетом, сервер запускается, /health=200 и /ready=503 без модели. Dockerfile, shell-скрипты, закреплённые зависимости и GitHub Actions подготовлены; Docker на этой машине отсутствует, сборка здесь не подтверждена.
- QA-01: выполнен общий прогон тестов; итоговый результат записывается в docs/VERIFICATION.md.
- DATA-03, ML-03 (оценка качества), ML-04, CV-01/02, VAL-01, UI-01, RELEASE-01: остаются открытыми. Наличие кода адаптера не означает наличие обученной модели качества.
- GitHub: на момент проверки репозиторий lve-qw/kosti не виден действующему аккаунту spideynyc228-star. Публикация кода/Issues не выполнена.

Субагенты сохранили реализацию; последующие вызовы были остановлены ошибкой кредитов рабочего пространства. Основной агент завершает интеграцию сохранённых файлов локально.

Исходные DICOM, Excel и архивы не коммитятся в GitHub. Для воспроизводимых тестов создаются синтетические DICOM без реальных персональных данных. Существующий notebook и checkpoint сохраняются локально неизменными.
